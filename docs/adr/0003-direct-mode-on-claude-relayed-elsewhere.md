# Direct mode on Claude Code, relayed mode elsewhere

Claude Code agent teams let Teammates message each other. Codex and Cursor subagents can only report to the Lead. Rather than run every agent in the lowest-common-denominator relayed flow, Claude Code keeps Direct mode, and Codex and Cursor get Relayed mode with the same Roles and steps. Direct debate is the project's most distinctive feature, so we accept two flows to maintain. When Codex or Cursor add peer messaging, move them to Direct mode.
