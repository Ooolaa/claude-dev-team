# Headline numbers compare against the same-rules baseline

The benchmark reports two comparisons, but the headline is the team versus one session with every Upstream installed (the same-rules baseline), not versus bare Claude Code. Beating bare Claude Code mostly measures the Upstream rule sets, which anyone gets by installing the plugins. Only the same-rules comparison shows what the team itself adds. Ponytail was publicly criticized (its issue #126) for a flattering baseline, and we chose the less flattering one on purpose. Don't swap the headline for the bigger number.
