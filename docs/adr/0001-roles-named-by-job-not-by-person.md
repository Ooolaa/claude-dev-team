# Roles are named by job, not by person or project

Roles were first named after their upstream authors or projects (Karpathy, Mattpocock, Steipete, Caveman). We renamed them by job (Skeptic, Planner, Builder, Gatekeeper, Reviewer, Design Lead, Art Director, Design Critic) and credit each upstream in the README. Person names implied an endorsement nobody gave. "Karpathy" was also misattributed: Andrej Karpathy didn't write andrej-karpathy-skills. We gave up the search and fame value of the names on purpose. Upstream authors can still be credited and tagged when launching.
